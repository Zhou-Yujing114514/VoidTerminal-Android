# 虚空终端 Android 版

一个功能丰富的安卓聊天应用，支持私聊、群聊、朋友圈、文件传输等功能。

## 功能特性

- 私聊、群聊、公共大厅
- 文字、图片、音频、文件消息
- 朋友圈动态
- 自定义背景
- 应用锁
- 群公告、群管理
- AI悬浮助手
- 消息撤回、引用、转发
- 已读状态
- 在线状态
- 自定义状态
- 站长管理

## 版本说明

- `releases/` 目录包含各版本APK
- `web/` 目录包含网页端代码
- 最新版本：v10.27
